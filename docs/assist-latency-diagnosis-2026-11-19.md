# 상담 assist 지연 진단과 변경

기준: 2026-11-19. 처음에는 `origin/develop` 262b864에서 Gemini 기준으로 작업했고, 이후 OpenAI 전환 브랜치(`refactor/openai-damage-response`) 위로 옮겼다.

## 진단 방법과 결과

실제 OpenAI 호출을 시험용 어댑터로 기존 LangGraph에 연결하고, 미승인 자료 45개를 메모리 안에서만 임베딩했다. 합성 질문 두 개와 15초 제한을 사용했으며, 아래 시간은 각각 1회 측정치다. 이 시험은 실제 Spring 연동을 검증하지 않는다. 미승인 자료의 판정을 서비스 품질로 간주할 수 없다.

변경 전 근거 질문: assess 2.696초(SEARCH), search 0.771초(10건), evaluate 6.935초(불충분·재검색 제안), 재검색 0.148초. 다음 판정 중 15초 시간 초과가 발생했다. 추가 질문은 5.00초에 NEED_USER_INPUT이었다. 로그는 질문·검색어·근거·모델 응답 원문을 담지 않는다.

변경 후 동일 시험에서 추가 질문은 3.29초에 NEED_USER_INPUT. 근거 질문은 10.18초에 UNABLE_TO_ANSWER/NO_EVIDENCE였으며, 평가 2회 모두 불충분으로 판정했다. 15초 이내 종료는 확인했으나 근거 부족 판정이 타당했는지는 검증되지 않았다. 1회 시험이므로 지연 개선을 보장하지 않는다.

## 구현

- 그래프 노드가 완료되면 request_id, 단계, 시간과 제한된 decision·개수·불리언·사실 키만 기록한다. 외부 호출 자체가 실패하거나 중단된 노드는 완료 로그가 없다.
- 재검색 기본 상한을 2회에서 1회로 줄이고 `ASSIST_MAX_RESEARCHES`로 0~2회 지정한다. 기본값에서 모델 판정은 최대 3회다. 재검색 전 남은 예산이 `ASSIST_RETRY_MIN_SECONDS`(기본 7초)보다 짧으면 NO_EVIDENCE로 종료한다. 예산 검사는 후속 재검색의 시간 초과 확률을 줄이지만, 최초 평가가 오래 걸리는 경우 등 모든 504를 막지는 못한다.
- 근거 판정 입력은 검색 상위 5개, 문단당 최대 600자다. 잘린 부분에 적용 조건이 있다고 추측하지 않도록 모델에 지시한다. Spring 승인과 ANSWER에는 코드가 전달되며 원문을 임의 수정해 승인 처리하지 않는다. 문단 절단으로 조건이 누락될 위험은 검수·평가가 필요하다.
- UNKNOWN이면서 미질문이고 의도 또는 질문에 연결된 사실만 allowedFactKeys로 모델에 전달한다. 목록이 비면 추가 질문을 금지하고 조건부 설명이 가능한 근거를 충분하다고 판정할 수 있도록 했다. 모델이 이를 무시하는 예외에는 남은 시간이 충분하고 최초 검색 단계일 때만 조건부 재판정을 한 번 수행한다. 여전히 위반하면 NO_EVIDENCE로 처리한다.
- `ASSIST_LLM_MODEL`은 비워 두면 `LLM_MODEL`을 사용한다. `ASSIST_REASONING_EFFORT=low`는 OpenAI `reasoning_effort=low`를 보낸다. 기본은 미설정이며, 추론 모델이 아니면 지원하지 않을 수 있으므로 배포 전에 확인한다.

## 검증 범위

가짜 모델로 최대 재검색, 남은 예산, 허용 사실 목록, 근거 개수·길이와 민감 내용이 로그에 없는지 검증했다. OpenAI 전환 후 재시도(429·500·503 한 번)는 tests/test_upstream.py로 검증한다. 이 브랜치에서 승인 근거를 사용한 Spring ANSWER 통합 시험은 수행하지 않았다.

## OpenAI 전환 후 실제 호출 확인 (2026-11-19, 각 1회)

`LLM_MODEL=gpt-6-luna`, `text-embedding-3-small`. 미승인 근거 45개로 임시 인덱스를 만들어 시험하고 삭제했다. 합성 질문만 사용했다.

| 시험 | 결과 | 시간 |
| --- | --- | --- |
| PLAN 송금 질문 → ANSWER | EVIDENCE_READY → ANSWERED (근거 1건 인용) | 8.00초 / 2.99초 |
| PLAN 앱 질문 | NEED_USER_INPUT (installedApp) | 3.72초 |
| PLAN 앱 후속(installedApp=YES) → ANSWER | EVIDENCE_READY → ANSWERED | 12.85초 / 7.46초 |
| PLAN 정보 유출 질문 → ANSWER | EVIDENCE_READY → ANSWERED | 8.17초 / 6.37초 |
| AI-06 사실 추출 | 200, 송금 YES·연락 NO | 2.25초 |
| AI-07 설명 (검색 5건) | 200, 근거 2건 인용 | 12.81초 |
| OCR 사진 분류 (문자 텍스트) | SMS, 요약 생성 | 2.31초 |

모두 15초 안에 끝났지만 앱 후속 PLAN은 12.85초로 여유가 적다. 근거가 미승인 자료이므로 답변 내용의 적절성은 검수 후 다시 평가해야 한다.
